# 捷途山海 L6 · 交互解剖

基于二维概念解剖图的交互式产品展示，包含发布会风格开场、九个部件热点、局部放大、拖动缩放、六站自动导览与明暗外观。

## 打开方式

**在线体验：[打开捷途山海 L6 交互解剖](https://lipu-2026.github.io/jetour-l6-interactive/)**

直接用浏览器打开 `index.html` 即可，全部图片、样式和脚本已内嵌，无需安装依赖或联网。

本仓库已开启 GitHub Pages，从 main 分支的根目录发布。

## 交互

- 点击图中光点或底部系统名称查看对应部件。
- 点击右侧局部图进入细节观察，支持继续缩放与切换部件。
- 在主图拖动平移、滚轮缩放，点击「复位」返回总览。
- 使用「自动导览」依次观看六个视角，可暂停与继续。
- 支持手机布局、键盘操作以及系统减弱动态效果设置。

## 图像与真实性范围

外观参考来自用户提供的捷途山海 L6 图片，解剖图为 AI 生成的概念可视化。内部布局、零件形状及紧固件位置未经原厂资料或实车核验。页面不是原厂技术资料，不可作为维修或装配依据，也不是可任意旋转的三维模型。

品牌与原始参考图片的相关权利属于各自权利人，本项目不宣称官方出品。

## 隐私与依赖

页面不收集数据，不使用统计脚本，不加载远程资源。明暗外观偏好仅保存在浏览器本地。仓库中的 `.nojekyll` 用于按普通静态文件发布。
